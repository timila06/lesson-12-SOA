# Demo Scenario 01 — Campus Lost Property Desk

Use this ungraded classroom exercise to practise GitHub Actions CI/CD with a small browser, API and database application. Start the supplied containers, add checks for each application image on pull requests, and run the integration smoke tests after a merge to `main`.

Use a practice repository and fictional records. The scenario and rubric provide a larger application exercise if time permits; the Lesson 12 focus is the CI/CD pipeline.
